## מצב נוכחי: שלב 1, עם ממשק ויזואלי
- **הממשק:** אפליקציה סטטית (Vite ו-React) בגובה המסך, בעברית ומימין לשמאל. יש בה שבעה מסכים:
  1. **בית:** גלובוס מסתובב של מקומות הלידה, עם מקרא שמסונכרן איתו.
  2. **עשרים הזוכים:** תמונת עבודה, תקציר בפורמט קבוע והייקו לכל זוכה.
  3. **ציר זמן:** הפעלה עם שעון שנים, ונקודות שמופיעות שנה אחר שנה.
  4. **חיי הרעיון (OpenAlex):** לכל זוכה, כמה עבודות ציטטו את המאמרים המובילים שלו בכל שנה, עם קו בשנת הפרס, ומי מבין הזוכים מצטט את מי.
  5. **רשת המנחים:** גרף כוחות חי, מנחים למעלה ותלמידים למטה.
  6. **גלובוס:** מסך מלא, עם סרגל שנים.
  7. **איכות הנתונים.**
- **איסוף:** כל 1,028 הזוכים ו-688 הפרסים מ-Nobel Prize API v2.1, עם תמונת מצב גולמית ב-`raw/`.
- **העשרה:** שמות בעברית ותאריכי לידה מ-Wikidata, ו-96 קשרי מנחה ותלמיד סביב 20 הנבחרים.
- **בחירה:** 20 זוכים ב-`config/selection.json`. אושר על ידי ענת, 2.11.2026.
- **תובנות:** 20 שלדי כרטיסים ב-`insights/`. השדות האישיים ממתינים לענת.
- **איכות:** `docs/QUALITY_REPORT.md`, ובממשק במסך "איכות הנתונים".

## הרצה מקומית
```
pip install -r requirements.txt
make build      # curated, שלדי כרטיסים, דוח איכות ו-data.json מה-raw הקיים
make test       # בדיקות Python
make web        # בונה את הממשק לתיקייה app/
make app        # שרת פיתוח של הממשק
make fetch      # משיכה חדשה מהמקורות (תמונת מצב חדשה ב-raw)
```

## עבודה על כרטיס תובנה
1. פותחים קובץ ב-`insights/`, למשל `2009-economics-846.md`.
2. ממלאים לפי השאלות המנחות. ציטוט עד 15 מילים, עם קישור.
3. כשהכרטיס גמור: `status: מאושר`. הכרטיס יופיע מלא בממשק, ובדיקה תיכשל אם חסר בו שדה.

## מבנה
```
raw/        JSON גולמי עם חותמת זמן (נובל, Wikidata). לא עורכים.
curated/    טבלאות CSV (laureate, prize, affiliation, edge, source, wikidata_check)
config/     selection.json, images.json (תמונות עבודה ורישיונות), museum.json (הייקו וציטוט)
scripts/    איסוף, בנייה, בדיקות איכות, ייצוא data.json לממשק
insights/   כרטיסי תובנה (Markdown + YAML)
web/        קוד הממשק (Vite, React, TypeScript, d3)
app/        הממשק הבנוי, מוגש כפי שהוא
tests/      בדיקות pytest
docs/       SPEC ודוח איכות
```
